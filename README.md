## 📌 Repository Overview

This repository contains the complete task deliverables for the **Oasis Infobyte Student Internship Program (OIBSIP)** in the **Web Development & Designing** track.

All tasks have been engineered with industry-standard web practices: semantic HTML5, modern vanilla CSS3 design systems (glassmorphism, micro-animations, responsive flex/grid layouts), vanilla JavaScript (ES6+), and zero third-party framework dependencies.

Every task includes:
- A built-in **2-second Video Title Card overlay** satisfying submission criteria (Full Name + Track + Task Title).
- Mobile-first responsive layouts.
- Standalone comprehensive documentation (`README.md`).
