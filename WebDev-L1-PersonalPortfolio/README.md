## 🎯 Project Objective
Create a modern, responsive personal portfolio website that showcases technical skills, projects, background, and contact avenues — functioning as a high-impact digital résumé.

---

## ✨ Features Checklist Compliance
- [x] **Profile / Hero Section:** Developer name, title, status indicator, bio, direct CTAs, and code mockup preview.
- [x] **About Me Section:** Overview of academic background in Computer Science & Engineering, Competitive Programming experience, and MERN stack mastery.
- [x] **Skills Matrix:** Categorized interactive skill filter (Frontend, Backend & DB, Core CS & DSA, Tools) with proficiency badges.
- [x] **Projects Section:** Showcase cards linking to OIBSIP deliverables with tech badges, preview links, and source code shortcuts.
- [x] **Education & Trajectory:** Timeline displaying academic history and internship track milestones.
- [x] **Contact Section:** Form with real-time input validation (Name, Email, Message) and direct contact cards (LinkedIn, GitHub, Email).
- [x] **Dark / Light Theme Switcher:** Saved to browser `localStorage`.
- [x] **Built-in 2-Second Title Card:** Overlay compliant with the Oasis Infobyte video submission guideline (displays Full Name, Track, and Task Title).
- [x] **Fully Responsive:** Tested across mobile, tablet, and desktop viewports with CSS Flexbox & Grid.

---

## 🛠️ Tech Stack
- **Structure:** HTML5 Semantic Elements
- **Styling:** Modern Vanilla CSS3 (Custom Properties, Glassmorphism, CSS Grid, Flexbox, Keyframes)
- **Scripting:** Vanilla JavaScript ES6+ (DOM Events, Validation, LocalStorage)
- **Typography:** Google Fonts (*Plus Jakarta Sans*, *JetBrains Mono*)

---

## 🚀 How to Run Locally
1. Clone or download the repository:
   ```bash
   git clone https://github.com/1rafi3/OIBSIP.git
   cd OIBSIP/WebDev-L1-PersonalPortfolio
   ```
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari) or use VS Code Live Server.
