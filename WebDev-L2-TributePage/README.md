## 🎯 Project Objective
Design and engineer an editorial tribute page celebrating Alan Turing — the Father of Theoretical Computer Science, AI, and cryptanalysis at Bletchley Park — employing multi-section color schemes, font pairings, structured biographical narratives, and an interactive cryptographic lab.

---

## ✨ Features Checklist Compliance
- [x] **Page Title & Tagline:** Prominent header declaring Alan Mathison Turing and his generational contributions.
- [x] **Prominent Portrait Image:** High-resolution historical portrait with caption frame.
- [x] **In-Depth Biographical Essay:** 4 rich, historically verified paragraphs covering his Cambridge research, Enigma codebreaking at Hut 8, the Turing Test, and posthumous legacy.
- [x] **Milestones & Achievements Timeline:** Chronological timeline cards spanning 1936 to 1952.
- [x] **Distinct Quote Block:** Memorable quotation block with unique typography and gold highlights.
- [x] **At Least 2 Distinct Background Colors:** Distinct themes across sections (Hero Navy `#090d16`, Biography Slate `#0f172a`, Quote `#131b2e`, Timeline `#0a0f1d`, Cipher `#060911`).
- [x] **At Least 2 Font Styles Explored:** Classical serif (*Cinzel*) for literary headings, modern sans-serif (*Plus Jakarta Sans*) for narrative body copy, and monospace (*JetBrains Mono*) for cryptographic components.
- [x] **Interactive Enigma Cipher Simulator (Bonus):** Real-time rotor/Caesar shift simulator reflecting Turing's Bletchley Park cryptanalysis.
- [x] **Fully Responsive:** Adapts elegantly across mobile, tablet, and desktop viewports.
- [x] **Built-in 2-Second Title Card:** Overlay compliant with the Oasis Infobyte video submission guideline.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic editorial structure (`<header>`, `<main>`, `<article>`, `<blockquote>`, `<figure>`).
- **CSS3:** Custom properties, multi-color palette, typography hierarchy, timeline tree.
- **JavaScript (ES6+):** Real-time text cipher manipulation engine and title card toggle.
- **Typography:** Google Fonts (*Cinzel*, *Plus Jakarta Sans*, *JetBrains Mono*).
