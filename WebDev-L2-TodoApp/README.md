## 🎯 Project Objective
Build an interactive task management application allowing users to manage daily objectives with add, complete, edit, and delete functionality, neatly organized into separate pending and completed boards with state persistence.

---

## ✨ Features Checklist Compliance
- [x] **Task Creation:** Input field + "Add Task" button with priority and category selection.
- [x] **Immediate Status Placement:** Newly created tasks appear instantly in the Pending board.
- [x] **Mark Complete Toggle:** Checkbox toggles task between Pending and Completed boards with immediate UI reactivity.
- [x] **Inline Editing:** "Edit" button replaces task text with an inline input for seamless edits upon pressing Enter or blurring.
- [x] **Task Deletion:** Permanent deletion button on every card.
- [x] **Dual Count Indicators:** Live counters for "X pending" and "Y completed" above each column.
- [x] **Bonus — Timestamps:** Displays task creation timestamp and completed timestamp.
- [x] **Bonus — LocalStorage Persistence:** Tasks, status, timestamps, and priority stay persistent across reloads.
- [x] **Empty State Messaging:** Friendly graphics and messages when a list has zero items.
- [x] **Resume Boosters:** Search & filter bar, completion progress percentage bar, and bulk clear for completed tasks.
- [x] **Built-in 2-Second Title Card:** Overlay compliant with the Oasis Infobyte video submission guideline.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic board layout and accessible input controls.
- **CSS3:** Modern dark UI, flexbox and CSS grid columns, priority color tokens.
- **JavaScript (ES6+):** Object-oriented state structure, DOM manipulation, keyboard event handlers.
- **Persistence:** Browser `localStorage`.
