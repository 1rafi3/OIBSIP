## 🎯 Project Objective

## ✨ Features Checklist Compliance
- [x] **Sticky Navigation Bar:** Fixed blur-glass header containing 5 navigation links and high-visibility CTA.
- [x] **Hero Section:** Dynamic headline, subheadline, interactive metrics bar, and primary/secondary CTA buttons.
- [x] **Bento Grid Features:** 5 asymmetric feature tiles highlighting multi-file context, zero latency, and security shielding.
- [x] **Architecture & Workflow:** 3-step structured cards demonstrating repository connection, AI collaboration, and production deployment.
- [x] **Interactive Pricing Matrix:** 3-tier cards (Hobbyist, Professional, Enterprise) with dynamic Monthly/Yearly toggle.
- [x] **Social Proof & Testimonials:** Grid of customer feedback with rating stars and profile badges.
- [x] **FAQ Accordion:** Interactive animated question-answer disclosure components.
- [x] **Semantic Footer:** Structured 4-column footer with social, product, and developer links.
- [x] **Consistent Color Palette & Clean Typography:** Deep space dark aesthetic with cyan/indigo accents and Google Fonts.
- [x] **100% Responsive Design:** Fluid layouts optimized across mobile, tablet, and widescreen.
- [x] **Built-in 2-Second Title Card:** Overlay compliant with the Oasis Infobyte video submission guideline.

## 🛠️ Tech Stack
- **HTML5:** Semantic architecture (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Bento Grid, Custom Properties, Glassmorphism, Keyframe animations.
- **JavaScript (ES6+):** Light DOM interactivity for pricing switcher, FAQ accordion, and title card.
